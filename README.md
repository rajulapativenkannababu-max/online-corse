# Learnova — Online Learning

A responsive online course discovery landing page made with HTML and CSS.

## Features
- Learning platform hero and call-to-action
- Course category filters (visual navigation)
- Featured course cards with level, duration and price
- Instructor highlights and learner testimonials
- Enrollment call-to-action and footer

## Run locally
Open `index.html` in a browser. This is a static front-end demo; enrollment links are sample interactions.

## Customize
Edit course titles, prices, instructor names and contact details in `index.html`. Artwork is stored locally in `images/`.

## Deploy
Create a GitHub repository, push these files, then enable GitHub Pages from the `main` branch and `/ (root)`.
